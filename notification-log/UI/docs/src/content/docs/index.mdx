Tutorial construido sobre el código real del repositorio: un contexto acotado de
**Notificaciones** en arquitectura por capas, y un portal de arriendos (**Llave**) encima.

Los fragmentos de código de estas páginas se importan directamente de los archivos `.cs` del
repositorio, así que no pueden quedar desactualizados respecto al código que documentan.

## Secciones

- **Proyecto** — qué hace la aplicación, cómo se levanta y cómo fluye una notificación.
- **DDD** — lenguaje ubicuo, value objects, entidades, agregados, repositorios y pruebas.
- **Arquitectura** — capas, estilos, decisiones tomadas y su evolución.
- **Patrones** — los patrones de diseño que aparecen en este código.
